# 逐玉 · Pursuit of Jade — Character Map

An interactive character relationship map for the Chinese drama **Pursuit of Jade (逐玉)**, covering Episodes 1–11.

Built with [D3.js](https://d3js.org/) as a single self-contained HTML file. No build step required.

## Features

- **Force-directed graph** — characters clustered by faction, connected by relationship type
- **Detail panel** — click any node to see bio, actor, aliases, and all connections
- **Filter sidebar** — filter by faction (Protagonists, Allies, Antagonists, Minor, Deceased) or debut episode range
- **Search** — fuzzy search by name, Chinese name, alias, or role (`⌘K`)
- **Zoom & pan** — scroll to zoom, drag to pan, or use the on-screen controls
- **Link labels** — toggle relationship labels on/off

## Relationship Types

| Type | Color |
|------|-------|
| Love / Marriage | Pink |
| Family | Gold |
| Friendship | Teal |
| Alliance | Light blue |
| Yearning | Purple |
| Enmity | Red |
| Conflict | Orange |

## Usage

Open `index.html` directly in a browser — no server needed.

Or visit the live hosted version on Cloudflare Pages.

## Characters

32 characters across 5 groups: Protagonists, Neutral & Allies, Antagonists, Minor, and Deceased.
